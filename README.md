# Data Engineer Portfolio Web Application

This repository contains the complete portfolio web application for **Amrith Deepesh (amrrtthh)**, pulled directly from Google Stitch (`projects/3788835668473384046`).

## 🚀 Features

- **Design System:** Obsidian Pipeline (Cinematic Minimalism + Cybernetic Precision)
- **Interactive Binary Matrix Canvas:** Custom two-stage particle scatter & reassemble animation (`[0/1]` controller with manual progress slider)
- **High-Speed Data Highway Warp Stream:** Interactive EXPLORE hyper-stream HUD overlay and viewport navigation
- **Academic Ledger:** Master of Computer Applications (Kristu Jayanti University) & Bachelor of Computer Applications (St. Aloysius College)
- **Featured Project Repositories Carousel:** Infinite looping carousel featuring *Hall-Ease*, *Game-Tour*, *Water-Quality-Risk-Analyzer*, *Pragcy-PWA*, and *Olivia*
- **Verified Credentials Carousel:** Verified certificates from Infosys Springboard, AWS, Microsoft & LinkedIn, Kaggle, IBM SkillsBuild, and Lernx
- **Responsive Navigation:** Fluid responsive layout (desktop, tablet, mobile) with frosted telemetry panels

## 💻 How to Run / Preview Locally

To preview the interactive canvas animations, start a local HTTP server:

### Option 1: Python
```bash
python -m http.server 3000
```
Then open `http://localhost:3000` in your browser.

### Option 2: Node.js (npx)
```bash
npx serve .
```

### Option 3: VS Code / IDE
Right-click `index.html` and select **"Open with Live Server"**.
